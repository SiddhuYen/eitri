eitri uses your own Anthropic API key, and requests are billed to it. Create one in the Anthropic Console , then paste it here.

No key yet? The recorded demos and the editor work without one.

What it costs

Expect about $0.24 per request on average across our 22-task benchmark (range $0.07 to $1.10 per task). Long design sessions cost more: the recorded V8 engine session in the demos cost $3.21.

Where the key is kept

In your eitri config file, readable only by you. Never in a project folder.

Nothing else leaves this computer

eitri makes no network calls except to Anthropic's API. Checking the key makes one free call that lists models.
